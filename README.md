# Yassine Cherni · Portfolio

Interactive 3D portfolio: **https://yassinecher.github.io/**

- 3D home (React Three Fiber): about, stack, experience, selected projects, contact
- Case studies for each project under `/projects/<slug>`; content lives in `src/data/`
- Built with Vite, Tailwind CSS 4 and React Router; deployed to GitHub Pages by `.github/workflows/deploy.yml`

```bash
npm ci
npm run dev
```
